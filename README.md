# LONSDALEITE · The Memory Archive

边伯贤 2024 亚洲巡演的非官方粉丝纪念网站。黑银色、钻石折射与舞台光束，沿时间轴覆盖 **14 座城市、29 场演出、15 个城市章节**，包含首尔两场 [dot] 安可。

## 本地运行

需要 Node.js 22.13+（推荐 Node 24）和 npm。

```sh
npm ci
cp .env.example .env.local
npm run dev
```

打开 `http://localhost:3000`。当前工作区已准备 `.env.local`，不需要覆盖它。默认使用 `data/lonsdaleite.db`，无需先安装数据库。

本地管理员邮箱为 `curator@example.com`。在登录框输入该邮箱，开发模式会在界面上显示六位验证码；验证后设置昵称。访问 `/admin` 可以维护内容和审核回忆。可在 `.env.local` 中修改 `ADMIN_EMAILS` 为自己的邮箱，多邮箱用逗号分隔。修改后重新启动服务并重新登录。

`DEV_EMAIL_MODE=true` 仅在非生产环境生效。它不会发送真实邮件，且不应将此开发服务器开放给公众。生产模式无论该变量是什么值，都不会向客户端返回验证码。

## 内容状态

日期与场馆已建立场次索引。第一版的城市舞台画面均为代码生成的概念视觉，页面明确标注。**真实照片、音频、逐场歌单、造型、互动记录与双语介绍仍待收集和核实**；没有虚构的粉丝留言或冒充现场照片的素材。

场次种子数据在 `src/lib/tour.ts`。首次启动会初始化全部场次，后续启动不会覆盖后台保存的修改。素材工作清单和场次核对来源见 `CONTENT_CHECKLIST.md`。

媒体描述与署名暂为一份原文；中文／英文切换覆盖界面、城市、场馆、介绍、现场记录与造型。粉丝留言保留原文，缺少档案译文时展示原文并标注待翻译。

## 服务配置

完整变量见 `.env.example`。

| 配置 | 用途 |
| --- | --- |
| `APP_URL` | 浏览器实际访问的站点根地址，生产使用 HTTPS；写请求按该来源校验 |
| `AUTH_SECRET` | 随机生成的至少 32 字符密钥，生产必填 |
| `ADMIN_EMAILS` | 可取得管理员角色的邮箱白名单，登录时同步角色 |
| `DATABASE_URL` | PostgreSQL 连接串；生产必填 |
| `SMTP_HOST/PORT/SECURE/USER/PASSWORD/FROM` | 事务邮件发送配置 |
| `S3_ENDPOINT/REGION/BUCKET/ACCESS_KEY_ID/SECRET_ACCESS_KEY/PUBLIC_URL` | COS／S3 媒体存储与公开 HTTPS 地址 |
| `S3_FORCE_PATH_STYLE` | 兼容要求 path-style 的 S3 服务；COS 默认 false |

未配置邮件时，生产登录返回“邮件服务尚未配置”，不会模拟成功。未配置对象存储时，生产上传也明确失败。`ALLOW_SQLITE` 和 `ALLOW_LOCAL_MEDIA` 仅为本机生产构建检查提供显式开关，不属于默认部署方案。

## 部署准备

项目带 `Dockerfile` 与 `compose.yaml`。可将应用部署到腾讯云服务器，将数据库换为托管 PostgreSQL，并将媒体配置到 COS。部署配置文件已提供，尚未连接实际云账户、域名、SMTP 或 COS，也未发布到公网。

使用附带的本机 PostgreSQL 容器时：

1. 创建 `.env.production`，填入 HTTPS `APP_URL`、随机 `AUTH_SECRET`、邮件配置、媒体配置，以及 `POSTGRES_PASSWORD`。数据库密码使用 URL 安全的随机十六进制字符串。
2. 执行 `docker compose --env-file .env.production up -d --build`。
3. 在服务器反向代理上终止 HTTPS，代理到 `127.0.0.1:3000`。限制上传请求为 26 MB，并设置合理的请求超时。
4. 数据库不对公网暴露；每日备份 PostgreSQL，COS 启用版本或备份策略。定期用备份做恢复检查。
5. 从大陆手机网络检查首页、中文字体、媒体与验证码送达后，再正式开放访问。

也可以直接运行 `npm run build` 与 `npm start`，由进程管理工具托管。生产 PostgreSQL／SMTP／COS 需要实际服务验证；当前自动测试使用隔离的 SQLite 与本地邮件模式。

## 代码结构

- `src/components`：网站交互与管理界面。
- `src/app/api`：邮箱、账户、投稿、审核、上传与媒体接口。
- `src/lib`：数据模型、双数据库适配、认证与校验。

公开接口只返回已公开档案关联的已通过留言，不返回邮箱、用户 ID 或驳回原因。会话使用 HttpOnly cookie；验证码摘要保存、有效期 10 分钟、最多尝试 5 次。审核接口在服务端校验管理员身份。
